# 🎯 InterviewGPT – AI Interview Coach using RAG + Groq

InterviewGPT is an AI-powered interview preparation platform that helps candidates improve their interview skills. The application analyzes resumes, processes interview questions, and generates detailed AI-powered interview feedback using Retrieval-Augmented Generation (RAG) and the Groq Large Language Model.

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/Archana-Golla123/InterviewGPT.git
```

### Navigate to the Project Folder

```bash
cd InterviewGPT
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Configure API Key

Create an environment variable named:

```text
GROQ_API_KEY=your_groq_api_key
```

---

## ▶️ Run the Project

```bash
streamlit run app.py
```
